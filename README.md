# Anil | Gameplay Programmer Portfolio

A high-end, professional portfolio website tailored for **Gameplay Programming** and **XR Development** roles. This project features a modern "Game UI" aesthetic with glassmorphism, HUD-inspired glow effects, and smooth reveal animations.

## 🚀 Live Demo
The site is designed for static hosting and can be deployed instantly on Netlify, Vercel, or GitHub Pages.

## 🎮 Key Features
- **Modern Game UI**: Deep black theme with Cyan HUD accents and glassmorphism panels.
- **Dynamic Projects**: Interactive "Case Study" cards showcasing technical depth and project highlights.
- **Tech Stack Grid**: A visual, animated pill-based grid of core competencies (C++, UE5, ROS2, etc.).
- **Mobile Responsive**: Fully optimized for smartphones and tablets with a custom slide-out navigation menu.
- **Reliable Contact Form**: Integrated with Formspree for direct email delivery without a server backend.
- **Performance Optimized**: Smooth 60fps scrolling with scroll-triggered reveal animations.

## 🛠️ Tech Stack
- **Frontend**: HTML5, Vanilla CSS3, JavaScript (ES6+)
- **Styling**: Modern CSS Grid & Flexbox, Custom Media Queries
- **Animations**: CSS Transitions & Intersection Observer API
- **Icons**: Font Awesome 5
- **Fonts**: Outfit, Space Grotesk (via Google Fonts)

## 📦 Deployment Instructions
This is a **static website**, meaning it does not require a server-side runtime like Node.js or Python.

### Deployment via Netlify (Recommended)
1. Drag and drop the project folder onto the **Netlify** dashboard.
2. Ensure `index.html` is in the root directory.

### Local Development
To view the site locally with auto-reload, you can use any static server (like Live Server in VS Code) or Python's built-in server:
```bash
python3 -m http.server 8000
```
Then navigate to `http://localhost:8000`.
